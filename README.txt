ASH CALL — FIXED SERVERLESS PWA

Upload index.html, manifest.json, sw.js and icon.svg to GitHub Pages.

On BOTH phones:
1. Open the same HTTPS GitHub Pages address.
2. Enter a different name on each phone.
3. Enter exactly the SAME private room code.
4. Tap Go online.
5. Wait until it says Ready.
6. Tap Call on one phone and Answer on the other.

IMPORTANT AFTER REPLACING AN OLD VERSION:
Because the previous PWA may be cached, close the installed app/browser tabs and reopen the site.
If it still shows the old interface, clear the site's cached data or uninstall/reinstall the PWA.

No custom Node/WebSocket server is included. Internet is required for Trystero peer discovery.
